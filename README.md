# matei-iliuta.github.io

My portfolio: the projects I build as an electronics student at ETTI UPB, with a build log for each one.

Live at https://matei-iliuta.github.io

Built with [Astro](https://astro.build) and published to GitHub Pages by the workflow in `.github/workflows/deploy.yml`.

## Run it locally

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # output in dist/
```

## Adding content

Every project is one Markdown file in `src/content/projects/`. See [docs/adding-projects.md](docs/adding-projects.md).
Events live in `src/data/events.json`.
